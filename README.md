# Canopy

Canopy is an institutional-grade platform for verified carbon credits. It bridges the gap between high-integrity forest restoration projects and corporate sustainability goals, offering a transparent, secure, and data-driven marketplace for carbon offsets.

## Features

- **Institutional Carbon Asset Marketplace**: Explore and purchase high-integrity forest carbon credits.
- **Impact Dashboard**: A comprehensive command center for corporate sustainability metrics, tracking total sequestered impact, ESG ratings, and more.
- **Verification Engine**: Real-time integration with forensic satellite data (LIDAR) and third-party audit trails to ensure environmental integrity and transparency.
- **Portfolio Management**: Manage carbon assets and track your organization's progress toward net-zero targets.

## Technology Stack

- HTML5 / CSS3 / JavaScript
- Vanilla CSS styling for flexibility and a premium, responsive design.
- Built with [Vite](https://vitejs.dev/) for fast and modern development workflows.

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Hafsa2122/Canopy-.git
   cd canopy
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the local server URL provided by Vite (typically `http://localhost:5173`).

## Project Structure

- `index.html`, `landing2.html`: Main landing pages.
- `marketplace.html`: The core marketplace for carbon credits.
- `dashboard.html`, `portfolio.html`: User/Corporate dashboards for tracking impact.
- `verification.html`, `audit.html`: Pages dedicated to transparency and audit trails.
- `contact.js`, `contact.css`: Shared logic and styling for the global contact modal.
- `public/`: Static assets (images, icons, etc.).
- `src/`: Additional source files.
