Science-Based Methodology

Carbon Sequestration Methodology

Canopy's carbon accounting methodology is built on peer-reviewed science, regulatory compliance, and continuous satellite telemetry. Every tonne we certify is defensible.

Core Methodology Pillars

Baseline Assessment

We establish a dynamic project baseline measuring what emissions would have occurred without the project using a counterfactual deforestation model.

  • Landsat-8 historical deforestation rate analysis
  • Regional pressure mapping (agricultural frontier modeling)
  • Benchmark comparison with reference zones
  • IPCC Tier 3 emission factor calibration

Real-Time Monitoring

Canopy's satellite stack continuously monitors forest cover changes using SAR, multispectral, and LIDAR fusion with 3m spatial resolution.

  • Monthly Sentinel-2 multispectral passes
  • Bi-annual LIDAR canopy density scans
  • Real-time SAR deforestation alert triggers
  • Ground-truth validation transects every 6 months

Additionality Proof

All projects must demonstrate they would not have been financially viable without carbon revenue — ensuring every credit represents genuine new protection.

  • Financial additionality barrier analysis
  • Regulatory surplus test against national laws
  • Absence of performance requirements test
  • Common practice test vs. regional norms

Permanence & Buffer Pool

A minimum 15% buffer pool is maintained per project to insure against unforeseen carbon losses from wildfire, disease, or illegal encroachment.

  • 15% buffer credit pool per project
  • Dynamic risk-weighted buffer adjustment
  • Permanent loss protocol for catastrophic events
  • Registry invalidation and replacement pathway

Sequestration Calculation Framework

The following equations represent the core carbon accounting formulas we apply to every registered asset.

ER = BLemissions − PLemissions − LK
ER = Emission Reductions | BL = Baseline | PL = Project Level | LK = Leakage
Cstock = AGB + BGB + DW + LT + SOC
Carbon stock pools: Above/Belowground, Dead Wood, Litter, Soil Organic Carbon
AGB = BA × H × ρ × CF × BEF
Above-ground biomass: Basal Area × Height × Wood Density × Carbon Fraction × Expansion
Leakage = α × (DRref × Cleakage belt)
Estimated displacement emissions outside project boundary
